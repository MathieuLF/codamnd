# Captures d'écran

Les captures servent au site, au README et aux notes de version.

Elles doivent toujours utiliser des données synthétiques.

Avant chaque commit, vérifier visuellement qu'elles ne montrent aucun nom, aucune donnée réelle, aucun chemin nominatif et aucun détail d'infrastructure. Utiliser des chemins neutres sous `C:\Users\Public\Documents`. L'audit de mise en ligne bloque toute capture nouvelle ou modifiée jusqu'à l'approbation explicite de son empreinte.
